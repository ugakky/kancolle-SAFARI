# KCS Safety iOS 専ブラ（非公式・個人利用向け）

iPhone / iPad 向けの非公式専用ブラウザです。Safari版とは別に、1枚の永続 `WKWebView` でDMMゲームページを表示し、艦隊情報・大破進撃ガード・遠征センター・メモリ診断をネイティブUIで提供します。

> 公式アプリではありません。一般公開・広告収益化を前提にせず、個人利用向けとして開発します。公式ロゴ・公式アプリアイコンは使用しません。

## 開発方針

- ゲーム本体が送受信する通信内容を書き換えない
- 自動出撃・自動遠征・自動操作など、プレイ操作を代行する機能は作らない
- ゲームが通常取得した情報を読み取り、表示・警告・計算に利用する
- 広告SDK・解析SDK・外部トラッキングSDKを組み込まない
- 端末内の状態表示と安全支援を優先する

## v0.2 遠征センター

### 遠征状態

- 第2〜第4艦隊の遠征状態
- 遠征名
- 帰投予定時刻
- 秒単位の帰投カウントダウン
- 艦隊ごとの艦数 / キラ数
- 未補給・大破の警告

### 遠征可否判定

v0.2初版では遠征ID 1〜21の主要条件をSwift側の条件DBで判定します。

- 艦数
- 艦種
- 旗艦Lv
- 合計Lv
- 空母系 / 潜水艦系などの編成条件
- 北方鼠輸送作戦のドラム缶装備艦数

未補給・大破・キラ状態は成功条件とは分けて警告します。条件DB未登録の遠征は推測でOK判定せず「条件DB未登録」と表示します。

遠征条件の実装は七四式電子観測儀の `MissionClearCondition` の考え方・既知条件を参照しつつ、iOS向けにSwiftで独立実装しています。イベントや仕様変更で条件が変わる可能性があるため、実機・実ゲーム側の挙動確認を優先します。

### 帰投通知

「遠征の帰投通知」をONにすると、受信した帰投時刻をもとにiOSローカル通知を予約します。

アプリをバックグラウンドで常時動作させるのではなく、帰投時刻を受信した時点で端末側へ通知を予約する方式です。

## 艦隊支援

- ページ内の XHR / fetch を `WKUserScript` で監視
- 必要な kcsapi のみ解析
- 第1〜第4艦隊タブ
- 艦名 / Lv
- HP
- Cond
- 燃料 / 弾薬
- 各スロット搭載数
- 通常艦隊 / 連合艦隊の出撃艦隊追跡
- 戦闘APIから戦闘後HPを計算
- 大破 / 中破 / 小破判定
- 航空戦の直近損失情報

Cond は未取得時に `0` とみなさず `? 不明` と表示します。

## 大破進撃ガード

- 戦闘結果で大破艦あり、またはHP判定不明の場合に赤いブロッカーを表示
- 約2.4秒以内に3回タップすると5秒だけ一時解除
- 解除後も実際の進撃操作はユーザー自身が行う
- 横幅 / 縦幅を20〜100%で変更可能
- X / Y位置も調整可能
- 設定は `UserDefaults` に保存
- 「確認」で4秒間プレビュー表示
- ブロッカーは検出したゲーム領域内へクランプ

## ゲーム領域認識

DMMページ全体や縦長iframeをゲーム本体とみなさず、候補iframeの上端から `1200:720 = 5:3` の領域だけをゲーム本体として扱います。

1200×720px固定ではありません。現在の横幅に対して高さを比率計算するため、縦向き・横向き・WKWebViewの表示サイズ変更に追従します。

## メモリ / WebKit診断

- iOSメモリ警告回数を上部バーに表示
- `webViewWebContentProcessDidTerminate` を検知
- WebKit終了回数を表示
- WebKit終了時は古いHP / Cond / 遠征情報を破棄
- 約0.7秒後に自動リロードして復旧を試行
- API取得数と最後に受信したAPIを表示

## 七四式電子観測儀系の今後の拡張

### 優先度 A

- 遠征ID 22以降の条件DB拡張
- 入渠艦 / 残り時間
- 建造 / 残り時間
- 資源・資材表示
- 艦隊制空値
- 索敵値
- 艦隊の未補給 / 疲労 / 大破状態一覧
- 入渠・建造完了のローカル通知

### 優先度 B

- 装備一覧 / 保有数 / ロック状態
- 艦娘一覧 / フィルタ / グループ
- 任務進捗の補助表示
- 海域ゲージ・基地航空隊状態
- 戦闘詳細 / 戦果予測補助
- 開発・建造・ドロップ履歴
- 資源推移レコード

### 優先度 C

- 羅針盤 / 次ノード情報の整理表示
- 図鑑ビュー
- スクリーンショット支援
- 画面レイアウトのカスタマイズ
- iPad向け複数ペイン表示

API仕様やイベント固有仕様によって正確に再現できない機能は、推測値と確定値を区別して表示します。

## 広告 / 外部SDK

広告機能は撤去しています。

- AdMobなし
- Google UMPなし
- 広告用App IDなし
- 広告プライバシーUIなし
- 外部トラッキングSDKなし

## ビルド

`project.yml` は XcodeGen 用です。

```bash
brew install xcodegen
cd ios
xcodegen generate
open KCSSafety.xcodeproj
```

Xcode 16 以降を使用します。

GitHub Actions でも以下を自動確認します。

1. XcodeGenでプロジェクト生成
2. iOS Simulator向けDebugビルド

## 現在の確認状況

- iOSアプリバージョン 0.2.0
- Xcode 16.4
- iOS Simulator向けコンパイル確認

実際のDMMログイン、ゲーム起動、遠征API、帰投通知、長時間海域でのメモリ挙動、大破ブロッカーの実位置はiPhone実機で確認が必要です。

## 安全上の注意

このツールのHP表示・遠征判定・大破ガードなどは補助機能です。API仕様変更・通信中断・WebKit再起動などで判定できない場合があります。イベント本番へ投入する前に通常海域で確認してください。
