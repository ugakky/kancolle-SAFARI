# kancolle-SAFARI — Safety v2.5

iPhone / iPad Safari + Userscripts 向けの非公式・受動型プレイ補助ツールです。

## 先に重要事項

**本ツールが利用規約に抵触しないことを保証するものではありません。** 過去の艦これ運営発言では、専用ブラウザやアドオンについて厳密には規約違反/抵触の可能性がある旨の言及があります。利用前に最新のDMM/艦これの規約・告知を確認してください。

v2.5ではリスクを最小化するため、ゲームサーバーへの追加リクエスト、API再送、通信改変、自動操作、マクロ、BOTを設計上禁止しています。

詳しい安全境界・取得内容・制約: [V2.5.md](V2.5.md)

## v2.5 のインストール

Userscripts で次の **2ファイルだけ** を有効にしてください。

1. `kancolle-page-bridge.user.js`
2. `kancolle-safety.user.js`

旧 `kancolle-audit-export.user.js` はv2.5でno-opです。DB書き出しはSafety本体へ統合しました。

### iPhone / iPad

1. App StoreからUserscriptsをインストール
2. 設定 → アプリ → Safari → 機能拡張 → Userscriptsを有効化
3. 上記2ファイルをUserscriptsの保存フォルダへ保存
4. DMM / 艦これゲームサーバーでUserscriptsの実行を許可
5. 艦これを完全に再読み込み
6. 右上に `⚓ 待機` が表示されればUI起動成功

## 機能

- 艦隊状態: 艦名 / Lv / HP / Cond / 燃料 / 弾薬 / 残量率
- 弾薬残量による与ダメージ補正の目安表示
- 大破判定
- 応急修理要員 / 応急修理女神の通常スロット・補強増設確認
- ダメコン確認済み大破: 黄色警告、ブロッカーなし
- ダメコンなし/判定不能大破: 赤白点滅 + 進撃ブロッカー
- ブロッカー左端は常にブラウザ画面端まで拡張
- ブロッカー右端/上下位置調整 + プレビュー
- ローカルPNGスクリーンショット
- `かんこれDB_YYYY-MM-DD_HHMMSS.json` 完全監査データ書き出し
- 任務ページ統合
- 海域/出撃/戦闘ログ
- 基地航空隊を方面ID+基地ID単位で統合
- 取得状況チェック

## かんこれDB

ゲーム本体が通常操作で受信したデータだけをセッション内で収集します。主な収録対象は、マスター、提督情報、艦娘、装備、艦隊、HP、Cond、資源、資材、アイテム、入渠、建造、遠征、任務、海域、基地航空隊、出撃ノード、戦闘結果です。

`api_token`、Cookie、ログイン情報、request bodyは保存・出力しません。

## 完全取得手順

追加APIを送らないため、未表示画面の情報をツール側から取りに行くことはありません。取得状況を見ながら通常操作で以下を表示してください。

`再読込 → 母港 → 編成 → 改装/装備 → 入渠 → 工廠 → 遠征 → 任務全ページ → 海域選択 → 基地航空隊がある各方面 → 必要なら通常出撃 → 母港 → 書き出し`

## 安全性CI

`scripts/safety-audit.mjs` と `.github/workflows/safety-audit.yml` で、以下の安全不変条件を静的チェックします。

- Bridgeが新規XHRを作らない
- `GM_xmlhttpRequest`を使わない
- Cookie APIを使わない
- request bodyから`api_token`を読まない
- Bridgeにクリック自動化がない
- ゲーム本体のXHR/fetchを各1回だけpass-throughする
- UI側がネットワークリクエストを発行しない
- 旧Auditが二重フックしない
- JavaScript構文チェック

CIは技術的な実装ミスを検出するためのもので、利用規約上の許可を保証するものではありません。

## Fail-closed

API仕様変更やデータ不足で大破/ダメコンを確実に判定できない場合、v2.5は安全側に倒して赤警告/ブロックします。

このツールは非公式です。艦これ / DMM / Safari / Userscripts の仕様変更で動作しなくなる可能性があります。
